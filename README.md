# SpaceX Falcon 9 Landing Prediction

IBM Applied Data Science Capstone. Predicts whether a Falcon 9 first stage will land successfully using API data, web scraping, SQL EDA, dashboards, and classification models.

## Scope

- Collect launch data from the SpaceX API and Wikipedia
- Clean and explore with pandas and SQL
- Visualize launch sites and payload patterns
- Build Folium maps and a Plotly Dash dashboard
- Compare Logistic Regression, SVM, Decision Tree, and KNN with GridSearchCV

## Notebooks

| Notebook | Purpose |
